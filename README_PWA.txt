NABUNG KITA — PWA

STRUKTUR GITHUB (semua file ikon di ROOT):
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

1. Upload semua file tersebut ke ROOT repository GitHub.
2. URL Google Apps Script sudah tertanam di index.html.
3. GitHub: Settings > Pages > Deploy from branch > main > /(root).
4. Buka URL GitHub Pages dari Chrome Android.
5. Pilih Install app / Tambahkan ke layar utama.
6. Ikon aplikasi menggunakan icon-192.png dan icon-512.png.

Jangan menaruh password, service-account key, atau rahasia lain di repository.
